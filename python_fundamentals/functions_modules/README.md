# Python - Functions & Modularity

## Description

This project introduces functions and modules in Python. It focuses on organizing code into reusable functions, understanding the difference between returning and printing values, and learning how Python files behave when they are executed directly or imported as modules.

## Learning Objectives

By completing this project, I will be able to:

* Define and use functions with parameters and return values.
* Understand the difference between `print()` and `return`.
* Use conditional statements and loops inside functions.
* Understand how Python executes top-level code.
* Use `if __name__ == "__main__"` correctly.
* Import functions from other Python files.
* Import variables from modules.
* Organize Python code into reusable modules.

## Requirements

* Ubuntu 20.04 LTS
* Python 3.8
* All files start with `#!/usr/bin/env python3`
* All files are executable.
* All files end with a new line.
* Code follows PEP 8 style using `pycodestyle`.
* No external libraries are used.

## Tasks

### 0. islower

Implements a function that checks whether a character is a lowercase ASCII letter without using built-in string methods.

### 1. To Uppercase

Implements functionality for converting lowercase ASCII letters to uppercase.

### 2. Print Last Digit

Implements a function that prints and returns the last digit of a number.

### 3. a ^ b

Implements a function that computes one number raised to the power of another.

### 4. Script Execution and Import Behavior

Explores how Python code behaves when a file is executed directly versus imported as a module.

### 5. Import a Simple Function from a Simple File

Demonstrates how to import and use a function from another Python file.

### 6. My First Toolbox

Uses multiple imported functions to perform different operations.

### 7. Everything Can Be Imported

Demonstrates how variables can be imported from another Python module.
