# Python - Inheritance & Polymorphism

This project explores inheritance and polymorphism in Python.

## Learning Objectives

- Understand inheritance in Python
- Identify parent and child classes
- Create subclasses
- Override inherited methods
- Understand polymorphism
- Use `isinstance()` and `issubclass()`
- Reuse methods and attributes through inheritance

## Class Hierarchy

BaseGeometry
    |
Rectangle
    |
Square

## Files

- `0-polymorphism_demo.py` - Introduction to inheritance and polymorphism
- `base_geometry.py` - Defines the BaseGeometry class
- `1-rectangle.py` - Defines Rectangle inherited from BaseGeometry

## Requirements

- Ubuntu 20.04
- Python 3.8
- PEP8 style
