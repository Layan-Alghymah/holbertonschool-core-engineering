# Python - Classes & Object Model

This project introduces Object-Oriented Programming (OOP) in Python and explores how classes and objects are used to organize data and behavior.

## Learning Objectives

By completing this project, I will be able to:

- Explain the difference between a class and an instance
- Create and use Python classes
- Define instance attributes using `__init__`
- Implement instance methods
- Understand object identity and types
- Apply basic encapsulation principles
- Use private attributes
- Validate attribute values
- Use getters and setters
- Implement special methods such as `__str__`
- Model simple real-world entities using classes
